What would change my mind

A dashboard that cannot be wrong is not an instrument, it is a poster. So, explicitly: here is what would falsify the case these signals are built to test.

  • The Engels gap stays near zero for a decade while output accelerates. Then labour income is keeping up, the pause is not coming, and the worry was misplaced.
  • Someone builds the zero-cost count and it climbs steeply. If the share of a decent-living basket available at near-zero marginal cost is rising fast, the money condition is dissolving without redistribution and the argument is answered.
  • The share below $30 a day falls sharply. Four in five people is the premise. Break the premise and the rest follows.
  • Someone shows CPI can detect demonetisation. The price channel here rests on an index that reweights away from anything whose price collapses. If that is wrong, the weakest part of this becomes the strongest.

Where I need you to push

Not rhetorical. The instrument is more useful once these are settled.

  • Define the zero-cost count. Which basket, where "close to zero" sits, and whether advertiser-funded-but-free-to-consumer counts. Three rulings and it exists.
  • Which CPI components are automatable? That split is the Baumol gap. The data is there; the judgement is not.
  • Cohort cuts. A national average can pass while the displaced cohort fails. That is precisely what happened during Engels' Pause and it is the biggest hole here.
  • Is asset ownership a third transmission channel? It is excluded. It is also the one that carried the wealthy through the last transition.

The snapshot contract

This page never talks to a data provider. It renders a snapshot: a dated, versioned JSON file pulled from open registries by a separate fetcher. That separation is deliberate, and it is what makes any future snapshot render here without touching this page.

open registries→fetch_snapshot.py→ snapshots/YYYY-MM-DD.json→this page

The page reads whatever is in the signals array. Add a signal to a future snapshot and it appears here. Remove one and it vanishes. No rebuild. Use Load snapshot… above to render any file that validates against schema 1.x.

Why snapshots and not a live feed. A live dashboard silently changes underneath an argument that cited it. A snapshot is dated, checkable and quotable: if someone disputes a number, they can be handed the exact file the claim was written against.
