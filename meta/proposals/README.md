# proposals

Drafts-in-waiting that are **not yet in the pipeline**.

`drafts/` is governed: each file there has a line-by-line review sheet, a
content hash and a pending sign-off from Fer. Rewriting one silently voids that
sheet. So a proposed rewrite lands here first, Fer compares it against the
current draft, and only then does it move into `drafts/` with its review
artefacts regenerated.

Nothing in this directory is approved, published, or his substance unless its
own frontmatter says so.
