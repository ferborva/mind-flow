# drafts

Pieces being written. Every file here is in motion.

`status` tracks where it is:

- **drafting** — being written. Rough is fine. `<!-- GAP: -->` markers welcome.
- **review** — complete enough to be checked. Two passes are required before it
  can move on:
  - *Provenance pass.* Every claim traced back to a capture. Anything that
    can't be traced is either cut, rewritten as scaffolding, or turned into a
    backlog question.
  - *Voice pass.* Read against `foundation/`. Does this sound like him?
- **ready** — both passes clean. Next scheduled run moves it to `posts/`.

A draft that has been sitting in `drafting` across several runs without moving
is usually blocked on missing material, not on effort. Add the question to
`meta/backlog.md` rather than writing around the gap.
