# Static reasoning slice, presentation edition 2.0.0

**A meaningful layout comparison is now prepared. It is still not a test of the integrated station.** This is Ren's commissioned presentation proposal, with no human study, appointment, recruitment, assignment, response collection or release approval.

Open the [conventional presentation](conventional.html) and [station-style reasoning slice](station.html). Both contain the same fourteen retained US facts and three tasks. The [reviewer answer sheet](reviewer.html) separately preserves the original proposed feedback and classifications. It is not a validated scoring rubric and must not be shown before a future held-out task.

This generator does not rewrite the preceding [rehearsal edition](../README.md), its source task pack, readiness summary, layouts or exposed feedback. This edition neither supersedes its research approvals nor obtains any: all human gates remain blocked.

## What changed

**The treatment is now a structured reading workspace versus a competent statistical release, not simply dark versus light paint.** The conventional page uses labelled tables and readable explanatory sections. The station-style page presents native reading cards beside assessment and authority, then follows the station's progression from limits to IF conditions, source scrutiny and bounded options.

Both layouts retain the same section order and neutral labels:

1. Read the change and its boundary.
2. Identify what is still missing.
3. Separate inquiry, conclusion and action.
4. Inspect the source and challenge the reading.
5. Consider the questions and options.

Denominator, reference/capture distinction, vintage, `cannot-say` explanation and authority are visible in the first reading section. They are not behind disclosures. Every fact appears once, with the same exact label and value. Each task includes the same title, prompt and alternatives. Deliberately unsupported alternatives are explicitly framed as task choices, not endorsed factual claims.

The neutral section labels, navigation and task-choice notice are shared presentation scaffolding, not additional measurements or recommendations. No new graph, synthetic series, forecast or causal explanation is introduced. The source package remains bound to the exact retained bytes.

This is a proposed estimand boundary, not an effect estimate. Its endpoint, worthwhile improvement, statistical design, sample and power remain unchosen. The author-supplied answers are preparation material, not evidence of reliability or validity. Moving feedback to another page does not establish that a future participant has never encountered it. Actual held-out cases and exposure control remain necessary.

Only two static presentation layouts are delivered. The earlier 2×2 interface-by-facilitation proposal remains a proposal: no facilitator delivery, timed exposure, random assignment or four-arm experiment is implemented here. ## Verification and access boundaries

The generator checks the source task-pack byte hash before building. The two layouts share an ordered material inventory, tasks and source references. A changed source pack cannot pass verification merely by supplying matching changed HTML. `--check` compares all four generated files with deterministic output; it does not fetch data or amend prior artefacts.

Tests cover exact source and visible-material inventories, shared section order, omitted feedback, visible critical boundaries, coherent substitution, escaping, no response controls and deterministic output. CSS is designed for narrow views and enlarged text; the source tests do not prove actual rendering or assistive access. Root performs a separate browser check. Any such check is software evidence, not human comprehension, accessibility certification or equal exposure across users.

The local return link is explicitly outside the proposed comparison. Navigating to the full station, following source links or encountering the reviewer page would need an exposure policy in a future operational protocol. Current pages impose none because no study is running.

## Reproduce

From the repository root, with Node 22.23.2 or a compatible TypeScript-stripping runtime:

```sh
node --test experiments/decision-experience/presentation-v2/presentation.test.mjs
node experiments/decision-experience/presentation-v2/presentation.mts --check
```

After an explicitly reviewed presentation change, `--write` regenerates only this directory's `conventional.html`, `station.html`, `reviewer.html` and `manifest.json`. It cannot grant authority or make recruitment ready. A successful check means the declared static edition reproduces.
