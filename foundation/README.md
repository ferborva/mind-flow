# foundation

The documents that calibrate everything written in this repository.

These are not content. They are the tuning fork. Claude reads them before
writing anything in Fer's voice.

| File | What it is | Provided by |
|---|---|---|
| `constitution.md` | Personal constitution — principles and commitments | Fer |
| `communication-style.md` | How he writes and speaks | Fer |
| `soul.md` | Soul representation | Fer |
| `editorial-guide.md` | What the three above imply, at sentence level | Claude, corrected by Fer |

The first three are his. Claude does not edit them — it may propose changes in
a conversation, but the files themselves change only when he says so.

`editorial-guide.md` is Claude's derived working document and is expected to
evolve as the writing reveals what actually works.
